## 构建 11 分钟假死：定位与结论
- `gradle.properties` 的 `org.gradle.daemon=false` → 每次 build 都是冷 JVM；实测正常 34 秒（另一次 1m13s）。
- 12:54 那次 daemon 日志停在 `ExecuteBuild` 之后一行都没有、classes 与 jar 时间戳仍停在 12:47 →
  是**初始化阶段就挂住**（非编译慢），进程被杀后 `journal-1.lock` 残留。
- 处理：删 `~/.gradle/caches/journal-1/journal-1.lock` → 重跑 `./gradlew build --offline --console=plain -x test`
  写日志再 tail（不再接 grep/head 管道），34 秒通过，jar 已部署（md5 `307ed7ff…`）。
- 记忆里加了「构建/部署」一节，写明别用管道、中断后清锁、只许 BUILD SUCCESSFUL 时 cp、换 jar 必须完全退游戏。
